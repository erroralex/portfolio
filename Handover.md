# Handover

## Overview
This document tracks recent changes, current context, and next steps for the Developer Portfolio SPA project.

## Recent Changes
- Disabled the project card parallax tilt effect (the mousemove-driven `rotateX`/`rotateY`/`scale3d` transform in `initTiltCards()`) per request, while keeping the searchlight hover glow active — it tracks the same `--mx`/`--my` cursor-position custom properties, so that handler stays live even with the tilt calculation commented out.
- Optimized oversized local image assets: `alx-logo.png` (980x483, 424KB → 480x237, 46KB), `cursor-app-icon.png` (1024x1024, 95KB → 160x160, 9KB), `drop-in-brain.png` and `lo-fi-ai.png` converted PNG→JPEG and downscaled (both were opaque with no real alpha channel use) — combined ~2.3MB down to under 250KB with no visible quality loss at their actual display sizes.
- Brought the four Latent Suite / Metadata Viewer project screenshots in-repo instead of pulling them live from their own separate GitHub repos via `raw.githubusercontent.com` (three were full 4K, up to 1.1MB each). Resized to 960px wide, JPEG-encoded, saved as `assets/latent-library.jpg`, `assets/latent-tools.jpg`, `assets/latent-model-organizer.jpg`, `assets/metadata-viewer.jpg`, and `index.html`'s project cards now point at these local files. Cuts ~2.5MB of external requests down to ~235KB served from the same origin, and removes a reliability dependency on those other repos staying public/unchanged.
- Stopped tracking local AI-assistant config in git: `CLAUDE.md`, `GEMINI.md`, `.agents/skills/*`, and `.claude/settings.json` are now in `.gitignore` and were untracked (`git rm --cached`) from the repo. They still exist on disk locally. Note: `AGENTS.md` (which these files alias/reference) is intentionally still tracked.
- Reworked the top nav to match the button/contact-card "top-glow" hover treatment: each `.nav-link` gets a permanent thin outline (matching `.btn-outline`) plus a top gradient glow line that fades in on hover and stays on for `.nav-link.active`, alternating teal/violet/blend across the five links the same way `.contact-link` and `.project-card` already do. Fixed several follow-on issues along the way: glow corners poking past the rounded border (needed `overflow: hidden`, like `.btn` already has), a stale desktop-only `border-bottom: none` reset that was zeroing the pill's bottom edge, the mobile dropdown picking up a boxed outline instead of its row divider, and the mobile glow centering on the full row instead of the word (each label is now wrapped in `.nav-link-text` so the glow can size to it).
- Rewrote the scrollspy in `script.js`: the old `IntersectionObserver` with a shrunk `rootMargin` band unreliably activated the tall Projects section and never activated Contact (the last section can't scroll far enough into the shrunk band). Replaced with a scroll-position check that walks sections top-to-bottom and marks the last one whose top has crossed the header offset as active, plus an explicit "scrolled to bottom of page" check.
- Brightened `--color-text-tertiary` from `#6B6E78` to `#8A8D97` after a contrast audit found it failing WCAG AA (3.6-3.9:1) everywhere it's used. All six usages now clear 4.5:1.
- Updated the GitHub profile README draft (`docs/README.md`, untracked in this repo — see note below) with a portfolio "hero card" matching the Latent Suite app card style, a two-tone badge CTA, and trimmed duplicate intro copy.
