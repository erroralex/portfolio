# Handover

## Overview
This document tracks recent changes, current context, and next steps for the Developer Portfolio SPA project.

## Recent Changes
- Fixed a bug where whole sections (About/Stack/Projects/Journey/Contact) could render as a permanent black void: they were `opacity: 0` by default in CSS and only an `IntersectionObserver` in `script.js` ever revealed them. A direct `#section` link (jumping straight past sections before the observer attaches), a blocked/slow script load, or an error thrown by an unrelated init function could all leave a section invisible forever. Reworked so sections are visible by default and JS has to opt a section *into* the hidden state (`.reveal-armed`) right before observing it; each init function in `script.js` now runs independently so one throwing doesn't take down the rest.
- Fixed a related first-load flash: on a browser/OS in dark mode, Chromium paints unstyled content with its own default dark-grey canvas (not white) until the page declares its color scheme, and an inline background rule alone doesn't stop that guess. Added `<meta name="color-scheme" content="dark">` plus `color-scheme: dark` on the inline `html,body` rule so the correct black paints from the first frame.
- Added a new project card for **Corpus Vera** (`erroralex/corpus-vera`, private repo): a config-driven news article/comment scraper with an admin UI and local-Ollama-assisted site drafting. Content (kind, stack, description, tags) was pulled from the repo's own README via `gh` (private, but authenticated). Styled like the other private-repo cards (Wiggy, Drop-in Brain, Lo-Fi AI) — "Private repo, not yet public" instead of a GitHub link.
- v1.1.2 – v1.1.5 (nav top-glow rework, scrollspy fix, contrast fix, image optimization + local screenshots, parallax disable, AI-config untracking, Corpus Vera card, the two fixes above) are live — see git log for that batch's detail if needed; not re-summarized here to keep this doc current rather than a running changelog.
- `docs/` (the GitHub profile README working copy plus old planning docs) is now gitignored and untracked from this repo entirely — those files live on disk locally only. Added `assets/readme-divider.svg`, a small brand-gradient bar image, referenced by the profile README as a bolder section divider than a plain `<hr>`.
- Pushed the reworked profile README to `erroralex/erroralex` (main): dropped the redundant "The Latent Suite" summary table (duplicated the per-app sections below it) in favor of a "My Projects" heading, added a Portfolio hero block (screenshot + live-site badge), and removed the Languages/Tools + GitHub-stats blocks at the bottom. Note: this also shortened the intro paragraph to "Open to new opportunities" from a longer bio that was live before — intentional per the working copy, flagged in case that wasn't wanted.
