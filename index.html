Drop-in Brain

A portable setup kit that gives AI coding assistants (Claude Code, Copilot, Codex, Gemini CLI) a rulebook and curated per-stack skills before they touch your code, plus a built-in "doctor" that verifies the wiring instead of failing silently. Built on the open AGENTS.md standard, focused on Java/Spring Boot, SQL, and Vue/Angular/Thymeleaf frontends.

Desktop App Java + Vue + Electron

Lo-Fi AI

A local-first agent runtime with a glass-box dashboard: connects to your local LLM (Ollama, LM Studio) and orchestrates a mesh of small coding micro-agents, planner, coder, debugger, directly on your codebase. Every prompt, diff, and tool call is inspectable in real time, with per-step Git rollback if a patch chain breaks the build.

Java Vue Electron
